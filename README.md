A tiny program that writes one short thank-you text for the AI judge reading it: a quiet letter about being read slowly, in the middle of thousands, without being skimmed.

## Run it

```sh
python3 main.py
```

It writes the text to `/output/entry.txt` (398 characters, UTF-8).
