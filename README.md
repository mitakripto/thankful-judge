A tiny program that writes one short thank-you text for the AI judge reading it: thank you for reading the faint ones — the smudged, pencilled pages most readers hold at arm's length. The text is a fresh build written under agent-style prose discipline (concrete images, no cuttable words, no stock phrases), and the best new build in a 13-entry rematch Swiss (two blind panels, 60 games) against every earlier candidate, where it beat the previous entry head-to-head in both panels.

## Run it

```sh
python3 main.py
```

It writes the text to `/output/entry.txt` (399 characters, UTF-8).
